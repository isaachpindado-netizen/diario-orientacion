# Diario de orientación

Diario para orientadores: previa de cada carrera (objetivo, foco, plan, calentamiento hacia atrás y checklist), resultado, parciales (IOF XML), errores clasificados, mapas anotados (Pensé / Hice) y análisis de temporada.

- Se instala en el móvil desde el navegador y funciona sin conexión.
- Los datos se guardan solo en tu dispositivo. Nadie más los ve.
- Copia en Excel (con hojas legibles de carreras y errores) y copia completa con mapas, para guardar en Drive, OneDrive o Archivos y para pasar a otro móvil.

## Instalar
- iPhone: abre el enlace en Safari → Compartir → «Añadir a pantalla de inicio».
- Android: abre el enlace en Chrome → menú → «Instalar app».

## Publicar una versión nueva
Sube los archivos cambiados. Cambia `VERSION` en `sw.js` en cada versión para que los móviles la reciban.
